## 🧮 Task 1 — Calculator

A fully functional browser-based calculator with a clean, grid-based button interface.

**Tech Stack:** HTML5, CSS3, JavaScript (Vanilla)

**Features**
- Display screen showing current input and result
- Numeric buttons (0–9) and decimal point
- Operators: addition, subtraction, multiplication, division
- Equals (=) button to evaluate expressions
- Clear (C) and Backspace/Delete buttons
- Division-by-zero handled gracefully with an error message instead of crashing
- Operator chaining for sequential calculations (e.g., `5 + 3 × 2`)
- Layout built with CSS Grid
- All interactions handled via `addEventListener` (no inline `onclick`)

## ✅ Task 3 — To-Do Web App

An interactive to-do list app for managing daily tasks.

**Tech Stack:** HTML5, CSS3, JavaScript (Vanilla)

**Features**
- Add new tasks via input field
- Tasks appear instantly in the Pending list
- Mark Complete toggle moves tasks to the Completed list
- Inline editing of task text
- Delete tasks from either list
- Live pending/completed task counters
- Empty-state messaging for empty lists
- Timestamps on tasks
- Persistence across page refreshes using `localStorage`

---

## 🔐 Task 4 — Login Authentication System

A client-side authentication system with registration, login, and a protected dashboard.

**Tech Stack:** HTML, CSS, JavaScript (localStorage-based)

**Features**
- Registration with username/email + password
- Password validation (min. 8 characters, at least 1 number)
- Duplicate account detection
- Login form with credential validation
- Generic error messaging for incorrect credentials (doesn't reveal which field is wrong)
- Protected dashboard — inaccessible without an active session
- Logout functionality that clears the session
- Passwords are hashed rather than stored in plain text
- Client-side form validation (no empty submissions)
