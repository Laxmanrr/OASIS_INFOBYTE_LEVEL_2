# LaxmanRathod_Task7 - To-Do List

## Oasis Infobyte Internship - Task 7

A simple To-Do List app with add, complete, delete, and filter functionality,
built with HTML, CSS, and JavaScript. Tasks persist across page refresh using
`localStorage`.

## Features
- Input field + Add button (also supports pressing Enter to add)
- Checkbox to mark tasks as complete (with strikethrough styling)
- Delete button to remove tasks
- Filter buttons: All / Active / Completed
- Remaining task counter
- Tasks persist after refresh via `localStorage`

## Tech Used
- HTML5
- CSS3 (card layout, filter buttons)
- JavaScript (array manipulation, localStorage, DOM rendering)

## How to Run
1. Download/clone this folder.
2. Open `index.html` in any web browser.
3. Add a few tasks, mark some complete, refresh the page — they'll still be there.

## Files
- `index.html` - to-do list structure (input, filters, list)
- `style.css` - styling for the task cards and filter buttons
- `script.js` - add/toggle/delete logic, filtering, and localStorage persistence
