# LaxmanRathod_Task3 - Calculator

## Oasis Infobyte Internship - Task 3

A simple, working calculator app built with HTML, CSS, and JavaScript.

## Features
- Display screen showing the current expression/result
- Number buttons (0-9) and decimal point
- Operator buttons (+, -, *, /)
- Clear (C) and Delete (DEL) buttons
- Equals (=) button to evaluate the expression
- Error handling (e.g. divide by zero shows "Error")
- Keyboard support (type numbers/operators, Enter to calculate, Backspace to delete, Esc to clear)

## Tech Used
- HTML5
- CSS3 (Grid layout)
- JavaScript (DOM manipulation, event handling, eval for expression evaluation)

## How to Run
1. Download/clone this folder.
2. Open `index.html` in any web browser.
3. Click the buttons or use your keyboard to perform calculations.

## Files
- `index.html` - calculator structure (display + button grid)
- `style.css` - styling for the calculator UI
- `script.js` - calculator logic (append, clear, delete, calculate)

## Note
This project uses JavaScript's `eval()` function to evaluate expressions, which is
fine for a learning/demo project like this but is generally avoided in production
applications for security reasons.
