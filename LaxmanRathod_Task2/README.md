# LaxmanRathod_Task4 - Tribute Page

## Oasis Infobyte Internship - Task 4

A tribute page honoring **Dr. APJ Abdul Kalam**, India's Missile Man and 11th President,
built with pure HTML and CSS.

## Features
- Semantic HTML structure (`header`, `main`, `section`, `figure`, `footer`)
- Main image with `figcaption`
- Bio section describing who he was and why he matters
- Timeline of key milestones and achievements
- Link to his Wikipedia page for further reading
- Clean, magazine-style responsive layout using Flexbox concepts

## Tech Used
- HTML5 (semantic tags)
- CSS3 (custom timeline layout, responsive design)

## How to Run
1. Download/clone this folder.
2. Open `index.html` in any web browser.

## Files
- `index.html` - page structure and content
- `style.css` - all styling, including the timeline design

## Notes
- The profile image is sourced from Wikimedia Commons (public domain / freely licensed image).
- No JavaScript was used, per the pure HTML/CSS approach for this task.
